# Application UI blocks

Inventory of the Preline "Application UI" collection (https://preline.co/blocks/application-ui/) and the Mica block that answers each category. Blocks are original designs built only with Mica components; they live in `site/app/blocks/<family>/<category>/` and are shown at `/blocks` on the site. Authoring rules: `site/app/blocks/README.md`.

139 categories (718 Preline variants) answered by 147 Mica blocks.
