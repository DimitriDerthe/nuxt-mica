# MiTraceCollapsibleContent

Expandable detail of a trace row; unmounted while closed unless keepMounted.

Group: Ai. Source: app/components/Ai/MiTraceCollapsibleContent.vue

## Props

| prop | type | default | notes |
|---|---|---|---|
| keepMounted | boolean |  | Keep children mounted (hidden) while closed, preserving nested open state. |

## Slots

- default: Detail shown while the row is expanded.
