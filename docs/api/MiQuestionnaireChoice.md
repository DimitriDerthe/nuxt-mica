# MiQuestionnaireChoice

Radio (single) or checkbox (multiple) choice inside a questionnaire item.

Group: Ai. Source: app/components/Ai/MiQuestionnaireChoice.vue

## Props

| prop | type | default | notes |
|---|---|---|---|
| value* | string |  | Value stored in the answer. |

## Slots

- default: Choice label; falls back to the raw value when empty.
