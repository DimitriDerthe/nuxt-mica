# MiAttachmentTrigger

Full-card overlay that opens a link or fires click, while actions stay independently clickable.

Group: Ai. Source: app/components/Ai/MiAttachmentTrigger.vue

## Props

| prop | type | default | notes |
|---|---|---|---|
| href | string |  | Renders an anchor when set, otherwise a button. |

## Slots

- default: Accessible content of the overlay, such as a visually hidden label.

## Emits

- click [e: MouseEvent]
