# MiTypography

Prose styles for headings, paragraphs, blockquotes, lists, inline code, lead and muted text.

Group: Base. Source: app/components/Base/MiTypography.vue

## Props

| prop | type | default | notes |
|---|---|---|---|
| variant | "small" \| "code" \| "p" \| "h1" \| "h2" \| "h3" \| "h4" \| "blockquote" \| "ul" \| "ol" \| "table" \| "lead" \| "large" \| "muted" | "p" | Style to apply; also picks the default element. |
| as | string |  | Element to render instead of the default. |

## Slots

- default: Content styled with the chosen prose variant.
