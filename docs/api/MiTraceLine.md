# MiTraceLine

Single trace row; status styles it as running, error or pending.

Group: Ai. Source: app/components/Ai/MiTraceLine.vue

## Props

| prop | type | default | notes |
|---|---|---|---|
| status | "error" \| "running" \| "pending" |  | Row status; omit for a finished row. |

## Slots

- default: MiTraceIcon, MiTraceTitle and MiTraceDescription for the row.
