# MiConfetti

Full-viewport, click-through canvas that draws confetti bursts fired with useMiConfetti(); mount it once near the app root.

Group: Feedback. Source: app/components/Feedback/MiConfetti.vue

## Props

| prop | type | default | notes |
|---|---|---|---|
| zIndex | number | 9999 | Stacking order of the canvas; it never receives pointer events. |
