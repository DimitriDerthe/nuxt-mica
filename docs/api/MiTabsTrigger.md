# MiTabsTrigger

Compound part of MiTabs: a tab button that selects the panel with the same value.

Group: Navigation. Source: app/components/Navigation/MiTabsTrigger.vue

## Props

| prop | type | default | notes |
|---|---|---|---|
| value* | string |  | Value shared with the matching MiTabsContent. |
| disabled | boolean |  | Dims the tab and prevents it from being selected. |

## Slots

- default: Tab label.
