# MiAttachmentMedia

Media slot of an attachment: an icon tile, or a full image when variant is image.

Group: Ai. Source: app/components/Ai/MiAttachmentMedia.vue

## Props

| prop | type | default | notes |
|---|---|---|---|
| variant | "icon" \| "image" | "icon" | `image` fills the tile with the slotted img. |

## Slots

- default: Icon or img shown in the tile.
