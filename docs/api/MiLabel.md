# MiLabel

Accessible form label bound to a control by id, with optional required marker and disabled styling.

Group: Base. Source: app/components/Base/MiLabel.vue

## Props

| prop | type | default | notes |
|---|---|---|---|
| for | string |  | Id of the control this label describes. |
| required | boolean |  | Show a required asterisk (hidden from assistive tech). |
| disabled | boolean |  | Dim the label to match a disabled control. |

## Slots

- default: Label text, shown before the required marker.
