# MiAspectRatio

Container that keeps its content at a fixed width-to-height ratio.

Group: Base. Source: app/components/Base/MiAspectRatio.vue

## Props

| prop | type | default | notes |
|---|---|---|---|
| ratio* | number |  | Width divided by height, e.g. `16 / 9`. |

## Slots

- default: Content sized to fill the ratio box, such as an image or video.
