# MiTextLink

Inline text link in brand colour with optional trailing chevron, for navigation in running text or CTAs.

Group: Buttons. Source: app/components/Buttons/MiTextLink.vue

## Props

| prop | type | default | notes |
|---|---|---|---|
| href | string | "#" | Destination of the link. |
| brand | "primary" \| "secondary" | "primary" | Color family of the link text. |
| chevron | boolean | true | Shows the trailing chevron. |

## Slots

- default: Text of the link.
