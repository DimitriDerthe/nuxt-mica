# MiSeparator

Thin line that visually or semantically separates content, horizontal or vertical.

Group: Base. Source: app/components/Base/MiSeparator.vue

## Props

| prop | type | default | notes |
|---|---|---|---|
| orientation | "horizontal" \| "vertical" | "horizontal" | Direction of the line. |
| decorative | boolean | true | Purely visual: renders with role="none" and no separator semantics. |
